Antes de empezar

  • Abre el sistema y confirma la compañía en la que vas a trabajar.
  • Para una solicitud: ten la lista de productos, cantidades, fechas, bodega y proyecto.
  • Para caja chica: ten los comprobantes, el proyecto, el centro de costo y el nombre de quien recibirá el pago.
  • Para un embarque: ten la factura, el proveedor y el número de orden.
  • Mantén la guía abierta en otra ventana para consultarla.

Realiza cada acción en el sistema de la empresa. La guía solo te orienta y no guarda ni aprueba solicitudes o facturas.

¿Cómo uso estas guías?

Lee el paso, realiza la acción en el sistema y presiona «Listo, siguiente paso». Usa «Volver» si necesitas revisar. Presiona una captura para ampliarla o usa «Aumentar letra». Cada guía recuerda su propia posición en este navegador cuando está disponible.
